This project analyzes U.S. House election data from 2012 to 2022 to examine the relationship between district competitiveness and political ideology. Using R (tidyverse), I cleaned and merged multiple large datasets, engineered key variables such as two-party vote share and ideological extremity (DW-NOMINATE scores), and conducted exploratory and statistical analysis. The project includes simulation modeling to evaluate sampling variability and regression analysis to identify predictors of ideological extremity. Results show that more competitive districts tend to elect more moderate representatives, while higher vote shares (safer seats) are associated with increased ideological extremity. This analysis highlights the distinction between correlation and causation in observational political data.
